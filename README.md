# 即売会 購入巡回表

同人誌即売会（コミケ等）の購入リスト管理・当日巡回支援Webアプリケーションです。

事前の購入リスト作成から、会場レイアウトマップとの連携、当日のリアルタイム巡回管理まで、即売会での買い物を一貫してサポートします。PWA対応のため、スマートフォンにインストールしてオフラインでも利用できます。

## セットアップ

### 必要環境

- Node.js 18以上
- npm

### インストールと起動

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` が自動的に開きます。

### ビルドとデプロイ

```bash
npm run build
```

`dist/` ディレクトリに生成される静的ファイルを任意のホスティングサービスにデプロイします。Vercel向けの設定ファイル（`vercel.json`）が同梱されています。

### PWAインストール

ブラウザのアドレスバーに表示されるインストールボタン、またはブラウザメニューの「ホーム画面に追加」からインストールできます。インストール後はオフラインでも動作します。

## 基本的な使い方

### 1. イベントの作成

アプリを起動すると **イベント一覧画面** が表示されます。初回はイベントがないため、データ取込画面から新しいイベントを作成します。

### 2. アイテムの登録

アイテムの登録方法は3種類あります。

#### スプレッドシートからの一括貼り付け

Google スプレッドシート等からタブ区切りデータをコピーして貼り付ける方法です。「一括登録」モードで最初のテキストエリアにペーストすると、各列に自動で振り分けられます。

対応列（左から順）：

| 列 | 内容 | 例 |
|---|---|---|
| サークル名 | サークルの名称 | サークルA |
| 参加日 | イベントの日付 | 1日目 |
| ブロック | 配置ブロック | ア |
| ナンバー | スペース番号 | 01a |
| タイトル | 頒布物のタイトル | 新刊セット |
| 頒布価格 | 価格（数値） | 1000 |
| URL | サークルのURL | https://... |

「備考」列は別途入力します。イベント名とスプレッドシートURLを入力し「登録」を押すと、イベントが作成されます。

#### CSVファイルからの読み込み

CSVファイル（`.csv`）を選択して読み込むこともできます。列の並びはスプレッドシート貼り付けと同様です。

#### 個別入力

「個別入力」モードに切り替えると、1アイテムずつフォームから入力できます。既存イベントへのアイテム追加や、マップ画面からの新規追加時にも使用されます。

### 3. 日付タブとモード

アイテム登録後、イベントを選択すると日付ごとのタブが表示されます。各日付タブには以下の3つの表示モードがあります。

- **編集モード** — リストの整理・巡回順の決定に使用
- **実行モード** — 当日の巡回時に使用
- **フォーカスモード** — スマートフォンでの当日巡回に最適化

タブをタップするとモードが切り替わります（編集 → 実行 → フォーカス → 編集...）。ヘッダーのモードボタン（✏️ / 🏃 / 🎯）でも直接切替可能です。

## 編集モード（リスト整理）

事前準備として、当日巡回するアイテムの選別と巡回順序の決定を行うモードです。

### 実行列と候補列

画面は2カラムに分かれています。

- **左：実行列** — 当日実際に巡回するアイテム。上から順に巡回する想定の並び順になります。
- **右：候補列** — 登録済みだが未整理のアイテム。ここから実行列に移動させます。

#### アイテムカードの情報

各アイテムカードには以下が表示されます。

- サークル名、ブロック・ナンバー
- タイトル、頒布価格
- 購入ステータスアイコン
- 優先度（設定時：⭐ 優先 / 🔥 最優先）
- 備考（設定時）

カードをタップするとステータスが切り替わります。長押しまたは右側のメニューから編集・削除が可能です。

### アイテムの選択と一括移動

1. アイテムカードの左端のチェックエリアをタップして選択
2. 複数選択可能（同じ列内）
3. ヘッダーの矢印ボタン（→ / ←）で選択アイテムを一括移動

選択中はヘッダーに選択件数と操作ボタンが表示されます。

### ブロックフィルタ

候補列のヘッダー部分に、登録されているブロック名がボタンとして表示されます。

- ブロックボタンをタップすると、そのブロックのアイテムだけが候補列に表示されます
- 複数ブロックを同時に選択可能
- 優先度付きの備考があるブロックは黄色でハイライトされます
- フィルタ中はナンバー昇降順ソートボタンが出現します

### 並び替え

ヘッダーの並び替えボタンで実行列のアイテム順を変更できます。

- **一括ソート**（↑↓ボタン）：ブロック→ナンバー順で昇順/降順ソート
- **ブロック順ソート**：ブロック単位でグループ化して並び替え
- 選択中のアイテムは上下ボタン（▲▼）で1つずつ移動可能

## 実行モード（当日巡回）

当日の巡回時に使用するモードです。編集モードの実行列に入れたアイテムだけが表示されます。

### 購入ステータス

各アイテムカードをタップすると、ステータスが順番に切り替わります。

| ステータス | 表示 | 意味 |
|---|---|---|
| None | （なし） | 未訪問 |
| Purchased | ✅ 購入済 | 購入完了 |
| SoldOut | ❌ 売切 | 売り切れ |
| Absent | — 不在 | サークル不在 |
| Postpone | ⏸ 後回し | 後で再訪問 |
| Late | 🕐 遅参 | 遅い時間に訪問 |

### サマリーバー

画面下部に固定表示されるバーで、以下の情報をリアルタイム表示します。

- 購入済み件数 / 全体件数
- 残りの合計金額（未購入＋後回し＋遅参のアイテムの合計）

### フィルタ表示

サマリーバーのフィルタボタンで表示するアイテムを絞り込めます。

- **全件表示** — すべてのアイテムを表示
- **未購入のみ** — ステータスが None のアイテムだけ表示
- **購入済み非表示** — Purchased 以外を表示

ヘッダーが非表示の設定時にも、サマリーバーからフィルタ操作が可能です。

## フォーカスモード（スマホ特化）

スマートフォンでの当日巡回に最適化されたモードです。1アイテムずつ大きく表示し、スワイプで次のアイテムに移動します。

### 3フェーズ巡回

巡回を3つのフェーズに分けて管理します。

1. **通常フェーズ** — メインの巡回。実行列の順序でアイテムを表示
2. **後回しフェーズ** — 「後回し」にしたアイテムを再巡回
3. **遅参フェーズ** — 「遅参」にしたアイテムを巡回

各フェーズの完了後、自動的に次のフェーズへの移行を提案します。

### マップ連携表示

画面を上下に分割し、上部にマップ、下部にアイテムカードを表示できます。現在のアイテムの位置がマップ上でハイライトされるため、会場内での位置確認が直感的に行えます。分割バーをドラッグしてマップとカードの表示比率を調整できます。

### アイテム操作

- **左右スワイプ** — 前後のアイテムに移動
- **カードタップ** — ステータス切替
- **＋ボタン** — 新規アイテムを追加（マップ上のセルからも追加可能）
- **価格入力** — 購入時に実際の支払額を入力可能

## マップ機能

Excelで作成された会場レイアウトマップを取り込み、アプリ内でインタラクティブに表示・操作できます。

### マップのインポート

1. イベント一覧画面で対象イベントを長押し → 「マップ読込」
2. Excel ファイル（`.xlsx`）を選択
3. インポートダイアログでシートを選択し、検出設定を調整
4. 「インポート」で取り込み

Excel ファイルはセルの背景色・罫線・結合情報・フォント色・縦書き設定を含めて忠実に再現されます。

#### ブロック自動検出設定

インポート時に以下のパラメータでブロックの自動検出を調整できます。

| 設定 | デフォルト | 説明 |
|---|---|---|
| ブロック名最大文字数 | 4 | これより長い名前は無視 |
| 許可文字種 | カタカナ・ひらがな・英字・漢字・数字 | ブロック名に使える文字 |
| 最小ブース番号数 | 1 | ブロック内の最低数値セル数 |
| ブロック名最小結合セル数 | 4 | ブロック名セルの最小結合数 |
| 数値セル範囲 | 1〜100 | ブース番号として認識する数値範囲 |

設定はイベントごとに保存され、次回インポート時に復元されます。

### ブロック定義

自動検出されたブロックの確認・修正と、手動でのブロック追加を行います。

1. マップタブを長押し → 「ブロック定義」
2. 既存ブロックの一覧が表示される
3. 「追加」でセル選択モードに入り、ブロックの範囲を指定

セル選択モードには以下の方式があります。

- **角指定** — 対角2点を指定して矩形範囲を選択
- **複数角指定** — 複数の角を指定してL字型等の複雑な範囲を選択
- **範囲始点指定** — 始点を指定して連続範囲を自動検出
- **個別指定** — セルを1つずつ選択

### ホール定義

大規模イベント（複数ホールにまたがる場合）では、マップ上にホール（エリア）を定義できます。

1. マップタブを長押し → 「ホール定義」
2. 「追加」で頂点選択モードに入る
3. マップ上で4〜6点の頂点をタップして多角形エリアを定義
4. ホール名を入力して保存

ホールを定義すると以下の機能が使えるようになります。

- ヘッダーのホールセレクタで表示ホールを切替
- ホールごとのアイテム数・実行列アイテム数の確認
- ホール巡回順序の設定

### マップ上の操作

マップ上のブース番号セルをタップすると、該当するアイテムのポップアップが表示されます。

- **実行列に追加** — タップで直接追加
- **位置指定追加** — 実行列内の挿入位置を指定して追加
- **実行列から除外** — 追加済みアイテムを除外
- **先頭/末尾へ移動** — 実行列内での位置変更
- **新規アイテム追加** — マップ上から直接アイテムを新規作成

実行列に入っているアイテムのセルには色付きマーカーが表示され、購入済み・未訪問等のステータスが視覚的に確認できます。

### スマートインサート

マップ上でアイテムを実行列に追加する際、巡回ルートを考慮して最適な位置に自動挿入する機能です。

- ヘッダーの「Smart」ボタンで ON/OFF 切替
- 長押しで「カード」モード（近いアイテムの隣に挿入）と「プレビュー」モード（挿入位置をプレビュー表示）を切替
- 有効時、マップからのアイテム追加が位置を考慮した順序になります

### 訪問先リスト

マップタブを長押し → 「訪問先リスト」で、実行列のアイテムをマップベースで並び替えるパネルが開きます。

- ホール定義がある場合、ホールごとにグループ化して表示
- ドラッグ＆ドロップで巡回順序を変更
- アイテムにタッチするとマップ上の位置がハイライト
- 「ホール順で並替」ボタンでホール巡回順に自動整列
- 変更は「確定」で反映、「キャンセル」で破棄

## イベント管理

イベント一覧画面では、各イベントに対して以下の操作が可能です。イベント名を長押しするとコンテキストメニューが表示されます。

### 更新（スプレッドシート再取込）

登録時に設定したスプレッドシートURLから最新データを再取得し、差分を確認してから反映します。

1. イベントを長押し → 「更新」
2. URL確認ダイアログ（URL・シート名を変更可能）
3. 差分確認画面が表示される
   - **追加されるアイテム** — 新規追加分
   - **更新されるアイテム** — 変更があった既存アイテム
   - **削除されるアイテム** — スプレッドシートから消えたアイテム
   - **保護されたアイテム** — 購入済み等で保護されているため変更されないアイテム
4. 「確定」で反映

#### 保護レベル

アイテムには保護レベルが設定されており、更新時の挙動に影響します。

| レベル | 更新 | 削除 | 自動設定条件 |
|---|---|---|---|
| full | 不可 | 不可 | 購入済み・売切・不在のアイテム |
| deletable | 不可 | 可 | — |
| none | 可 | 可 | デフォルト |

スプレッドシートから取り込んだアイテムは初期状態で `none`、アプリ内で手動追加したアイテムは `deletable` になります。ステータスを変更すると自動的に保護レベルが調整されます。

### エクスポートとインポート

イベントデータをExcelファイル（`.xlsx`）として書き出し・読み込みできます。

#### エクスポート

1. 長押し → 「エクスポート」
2. エクスポートオプションを選択
   - アイテムリスト
   - レイアウト情報（実行列の配置）
   - マップデータ
   - ブロック定義
   - ルート情報
3. ファイルがダウンロードされる

#### インポート

1. イベント一覧画面の「インポート」ボタン
2. エクスポートした `.xlsx` ファイルを選択
3. イベントが復元される

端末間のデータ移行や、バックアップ・復元に利用できます。

### リネーム・削除

- **リネーム** — 長押し → 「リネーム」で新しいイベント名を入力
- **削除** — 長押し → 「削除」で確認後に完全削除（復元不可）

## その他の機能

### テーマ切替

ヘッダー右上のテーマボタンで3モードを切り替えます。

- ☀️ **ライトモード**
- 🌙 **ダークモード**
- 🖥️ **システム設定に連動**

### ズーム

画面右下のズームコントロールで表示倍率を 30%〜150% の範囲で調整できます。アイテムリストとマップの両方に適用されます。

### レイアウトモード

サマリーバー右端のボタンで切り替えます。

- **PC/タブレットモード** — 横幅を活かした2カラム表示等
- **スマートフォンモード** — 縦長画面に最適化された1カラム表示

初回起動時は画面幅に応じて自動判定されます。

### UI表示設定

ヘッダーの歯車ボタンから、フォーカスモード・実行モード時のUI要素の表示/非表示をカスタマイズできます。

#### フォーカスモード設定

スマートフォン×マップON/OFF、PC×マップON/OFF の4パターンごとに、以下を個別設定可能です。

- ヘッダーの表示/非表示
- タブバーの表示/非表示

#### 実行モード設定

スマートフォン、PC/タブレット の2パターンごとに同様の設定が可能です。

UI非表示時は画面左上にフローティングの「全表示」ボタンが出現し、一時的にUI要素を復帰できます。

### 検索

ヘッダーの虫眼鏡ボタンで検索バーを表示し、サークル名・タイトル・ブロック・ナンバー等をキーワード検索できます。ヒットしたアイテムがハイライト表示され、次/前ボタンで順に移動できます。

## データの保存

すべてのデータはブラウザの **IndexedDB** にローカル保存されます。サーバーへのデータ送信は一切行いません。

- データは自動的に保存されます（デバウンス処理付き）
- 初回起動時、旧バージョンの localStorage データがあれば自動でマイグレーションされます
- ブラウザのデータ消去を行うとすべてのデータが失われます。重要なデータは定期的にエクスポートしてバックアップしてください
