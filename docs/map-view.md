# マップ表示時の操作方法

マップ表示では、取り込んだ会場マップ上でスペース位置を確認しながら、アイテムを実行リストへ追加したり、巡回ルートやホール単位の順序を確認できます。

## マップ表示を開く

1. イベントを選択します。
2. マップを取り込んだ参加日タブを開きます。
3. ヘッダーのマップアイコンを押します。

マップ表示中に同じマップアイコンを押すと、リスト表示へ戻ります。

## マップアイコンの長押しメニュー

マップ表示中にヘッダーのマップアイコンを長押しすると、関連メニューが開きます。

- `訪問リスト`: 実行リストの訪問順をマップ連動で確認・調整します。
- `ブロック定義`: マップ上のブロック範囲や番号セルを編集します。
- `ホール定義`: マップ上でホール範囲を定義します。

通常の閲覧や実行リスト追加だけであれば、長押しメニューを使う必要はありません。マップの認識結果や巡回順を調整したい場合に使います。

## マップの移動・拡大縮小・回転

マップ本体はドラッグで移動できます。PCではマウスドラッグ、スマートフォンやタブレットでは1本指のドラッグで表示位置を動かします。

拡大縮小:

- PC: マウスホイールで拡大・縮小します。
- スマートフォン: 2本指のピンチ操作で拡大・縮小します。

左下には現在のマップ倍率が表示されます。倍率や表示位置は参加日ごとに保存され、次回マップを開いたときに再利用されます。

回転:

- ヘッダーの回転コントロールで地図を回転できます。
- PCでは、マップ上で `Shift` を押しながらマウスホイールを動かすと15度刻みで回転できます。
- 回転コントロールのリセットは、マップ取り込み時に設定した初期角度に戻ります。

## セルをクリックしてアイテムを確認する

番号セルをクリックまたはタップすると、そのスペースのポップアップが開きます。ポップアップには、そのセルに紐づくアイテムが表示されます。

ポップアップで確認できる内容:

- ブロック名と番号
- 該当アイテム数
- サークル名
- タイトル
- 頒布価格
- 備考
- 購入状態
- 実行リストに入っているかどうか

ブロック名セルや、番号として登録されていないセルを押しても、通常はポップアップは開きません。

## アイテムを実行リストへ追加・解除する

セルのポップアップ内でアイテムを押すと、実行リストへ追加できます。すでに実行リストに入っているアイテムには `訪問先` 表示とピンが付きます。

実行リストに入っていないアイテム:

- アイテムをタップすると実行リストへ追加されます。

実行リストに入っているアイテム:

- アイテムをタップすると実行リストから外されます。

同じスペース番号に複数の枝番がある場合、ポップアップ上部に枝番ごとの小さなボタンが表示されます。このボタンを押すと、その枝番グループをまとめて実行リストへ追加または解除できます。

## スマート挿入

スマート挿入が有効な場合、マップからアイテムを実行リストへ追加するときに、既存の訪問順に近い場所へ入れられます。

同じブロックで番号が近い訪問先がすでに実行リストにある場合、`追加位置を選択` ダイアログが表示されます。

選べる追加位置:

- `この上に追加`
- `この下に追加`
- `同ホールの末尾に追加`
- `リスト末尾に追加`

ヘッダーのスマート挿入ボタンで有効・無効を切り替えられます。長押しすると、追加位置ダイアログの表示方式を `カード` と `プレビュー` で切り替えられます。

同じブロックかつ同じ番号+アルファベットのプレフィックスを持つアイテムがすでに実行リストにある場合は、その並びの直後に自動挿入されます。

## 新規アイテムを追加する

セルのポップアップにある `新規アイテム追加` を押すと、そのセルをもとに新しいアイテムを追加できます。

追加時には、参加日、ブロック、番号が現在のセルに合わせて初期入力されます。サークル名、タイトル、価格、数量、購入状態、備考、URLを入力して追加します。

サークル名は必須です。

## アイテムを編集・削除する

セルのポップアップ内でアイテムを長押しすると、操作メニューが開きます。

- `編集`: アイテム情報を編集します。
- `URLを開く`: 登録済みURLを開きます。
- `削除`: アイテムをリストから削除します。

編集では、サークル名、タイトル、頒布価格、数量、購入状態、優先度、備考、URLを変更できます。優先度を変更すると、ホール順序や実行リストの並びにも反映されます。

## ホールを絞り込む

ホール定義がある場合、ヘッダーにホール選択ボタンが表示されます。

`全ホール` を選ぶとマップ全体を表示します。特定のホールを選ぶと、そのホールに属するセルとアイテムを中心に表示し、実行リスト対象もそのホールに絞り込まれます。

ホール選択メニューには、各ホールの `実行リスト入り件数 / 総アイテム件数` が表示されます。

## ルートを表示する

ヘッダーのルート表示ボタンで、巡回ルートの表示・非表示を切り替えられます。

ルートは実行リストの順序をもとに描画されます。ホール定義がある場合は、特定ホールを選択しているときに、そのホール内のルートを確認しやすくなります。

ルート描画では、番号セルや塗りつぶしセルを避けるように経路が計算されます。通れる場所・通れない場所の作り方は [map-import.md](</d:/event-shopping-planner-routeplanning-51d2abc15fe23ddc4d1ab80949d0b5b0e8bcf145/docs/map-import.md:1>) を参照してください。

## ホール順序を編集する

ホール定義がある場合、ヘッダーのホール順序ボタンから `ホール間移動順序` を開けます。

この画面では、訪問先があるホールグループの巡回順を上下ボタンで変更できます。優先・最優先のアイテムがある場合は、通常のホールとは別のグループとして表示されます。

操作:

- `▲` / `▼`: ホールグループの順序を変更します。
- `保存`: ホール順序を保存します。
- `実行列を並び替え`: 現在のホール順序に従って実行リストを並び替えます。
- `キャンセル`: 変更を保存せずに閉じます。

訪問先がないホールグループは、スキップ対象として下部に表示されます。

## 訪問リストを確認・並び替えする

マップアイコンの長押しメニューから `訪問リスト` を開くと、実行リストの訪問順をマップと照らし合わせながら確認できます。

訪問リスト内のアイテムにマウスを重ねると、対応するマップセルが強調表示されます。PCではドラッグで並び替えできます。スマートフォンではアイテムを長押ししてからドラッグします。

訪問リストでできること:

- ホール単位で訪問先を確認する
- グループを折りたたむ
- アイテムまたはスペース単位で順序を入れ替える
- 範囲選択や入れ替え操作で順序を調整する
- 優先度を変更する
- 変更を保存または破棄する

`保存して確定` を押すと、変更後の訪問順が実行リストに反映されます。未保存の変更がある状態で閉じようとすると、保存するか破棄するかを確認されます。

## ブロック定義を編集する

マップアイコンの長押しメニューから `ブロック定義` を開くと、取り込み時に自動検出されたブロック範囲を調整できます。

主な用途:

- ブロック名の修正
- ブロック範囲の再選択
- 複数範囲に分かれたブロックの設定
- 個別セルの追加
- 壁ブロックの設定
- ブロック色の変更

セル選択中は、画面下部に選択状況が表示されます。必要なセルを選んだら `選択を確定` を押します。選択をやめる場合は `キャンセル` を押します。

## ホール定義を編集する

マップアイコンの長押しメニューから `ホール定義` を開くと、マップ上の頂点を選択してホール範囲を作成できます。

ホール定義中は、マップ上で頂点をクリックして多角形を作ります。4から6個の頂点を選択できます。画面下部には選択済みの頂点数が表示されます。

補助グリッドや補助ルーラーをオンにすると、頂点を選びやすくなります。マーカーをクリックすると、選択済みの頂点を解除できます。

ホール定義は、マップの絞り込み、ホール順序、実行リストの並び替え、集中モードの巡回順に使われます。

## マップ表示で保存される状態

マップ表示では、次の状態が保存されます。

- マップの表示倍率
- マップの表示位置
- マップの回転角度
- ホール定義
- ホール順序
- ホール別の訪問リスト
- 実行リストの追加・解除結果

表示倍率と表示位置はマップタブごとに保持されます。回転角度は通常のマップ表示用と集中モード用で別に保持されます。

## ルート順序

- マップのルート番号と線の順序は、実行列の表示順に従う。
- 優先度変更で実行列がホール/優先度グループに分かれる場合、マップ上のルート番号と訪問リストパネルの番号も同じ順序に更新される。
- 同一セルに複数の訪問アイテムがある場合、そのセルの番号は最初に出現した route index を表示する。番号は詰め直さない。
- 参加日名の比較では全角スペースを半角スペースに寄せ、前後空白を無視する。
- 保存済みの実行列 ID 配列自体は、この表示調整では変更しない。
