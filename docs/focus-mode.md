# 集中モードの操作方法

集中モードは、実行リストに入れたアイテムを訪問先ごとに1か所ずつ表示し、当日の購入チェックに集中するための画面です。編集モードで実行リストを組み、実行モードで全体を確認したあと、現地で順番に巡回するときに使います。

## 集中モードを開く

1. `イベント一覧` から対象の即売会リストを選択します。
2. 操作したい参加日タブを開きます。
3. ヘッダー右側の `集中モード` を押します。

集中モードには、現在の参加日の実行リストに入っているアイテムだけが表示されます。実行リストが空の場合は、訪問先がないことを示す画面が表示され、`編集モードへ` から実行リストの作成に戻れます。

## 基本の流れ

1. 画面上部に表示された現在の訪問先を確認します。
2. 表示中のアイテムカードで、購入状態・数量・価格・備考を必要に応じて更新します。
3. その訪問先の確認が終わったら、次の訪問先へ進みます。
4. 通常フェーズが終わったら、後回しフェーズ、遅参フェーズの順に確認します。
5. すべての訪問先を確認すると、完了画面に購入結果の集計が表示されます。

PC表示では左右の丸いナビゲーションボタンで前後の訪問先へ移動できます。スマートフォン表示では、左スワイプで次へ、右スワイプで前へ移動できます。

## 訪問先のまとまり

集中モードでは、同じ参加日・ブロック・基本番号・優先度のアイテムが1つの訪問先としてまとめられます。

たとえば `A-01a` と `A-01a2` のように同じ基本番号に属するアイテムは、同じ訪問先として表示されます。優先度が異なるアイテムは、同じスペースでも別の訪問先として扱われます。

## 画面上部で確認できる内容

画面上部には、現在処理している訪問先の情報が表示されます。

- `訪問先`: ブロックとスペース番号です。
- サークル名: 現在の訪問先のサークル名です。
- チェック数: 現在の訪問先で、購入状態が未購入以外になっている件数です。
- `総額`: 現在の訪問先で購入済みになっているアイテムの合計金額です。
- `フェーズ`: `通常`、`後回し`、`遅参` を切り替える選択欄です。
- `次`: 次に表示される訪問先です。

価格未定の購入済みアイテムがある場合、総額には `価格未定` または未定件数が表示されます。

## 購入状態を変更する

各アイテムカードでは、購入結果に応じて購入状態を変更します。

- `未購入`: まだ確認していない状態です。
- `購入済`: 購入できた状態です。
- `売切`: 売り切れだった状態です。
- `欠席`: サークルが不在だった状態です。
- `後回し`: あとで再訪問する状態です。
- `遅参`: 遅れて来るサークルとして再確認する状態です。
- `限数`: 購入制限などがあり、予定どおり買えなかった状態です。

購入状態の操作方法は、表示設定の `購入状態のボタン` によって変わります。循環クリックの場合は押すたびに次の状態へ切り替わり、メニュー方式の場合は状態一覧から直接選択します。

## 訪問先内の一括操作

訪問先の上部には、現在の訪問先に含まれる全アイテムをまとめて変更するボタンがあります。

- `全購入`
- `全売切`
- `全欠席`
- `全後回`
- `全遅参`
- `全限数`

ボタンを押すと、その訪問先の全アイテムが指定した状態になります。すでに全アイテムが同じ状態になっているときに同じボタンをもう一度押すと、全アイテムが `未購入` に戻ります。

通常フェーズ中に訪問先内の全アイテムを `後回し` または `遅参` にすると、3秒のカウントダウン後に自動で次の訪問先へ進みます。カウントダウン中に状態を変更すると、自動移動は解除されます。

## 次の訪問先へ進む

次へ進むとき、購入済みなのに価格が未定のアイテムがある場合は、通常は次の訪問先へ進めません。該当する価格欄が強調表示されるため、価格を入力してから再度進んでください。

表示設定で `価格未定チェックを無効化` をオンにしている場合は、警告表示を残したまま次へ進めます。

未購入のアイテムが残ったまま次へ進むことはできます。ただし、次へ進んだあとに `前のサークルでチェック漏れがあります` という通知が表示されます。

## フェーズを切り替える

集中モードには3つのフェーズがあります。

- `通常`: 実行リストの訪問先を巡回する通常のフェーズです。
- `後回し`: `後回し` にしたアイテムを含む訪問先だけを再確認するフェーズです。
- `遅参`: `遅参` にしたアイテムを含む訪問先だけを再確認するフェーズです。

通常フェーズの最後まで進むと、後回し対象があれば後回しフェーズへ、遅参対象があれば遅参フェーズへ自動で移ります。該当する訪問先がないフェーズはスキップされます。

画面上部のフェーズ選択欄から手動でフェーズを切り替えることもできます。切り替え先に途中位置が保存されている場合は、最初から始めるか、保存された位置から再開するかを選べます。

## 地図を表示する

対象イベントにマップ情報がある場合、フッターの地図アイコンで地図の表示・非表示を切り替えられます。

地図表示中は、現在の訪問先、前後の訪問先、巡回ルートを確認できます。PC表示では地図とアイテムリストが左右に分かれ、スマートフォン表示では上下に分かれます。スマートフォン表示では、中央の区切りをドラッグして地図とリストの高さを調整できます。

地図上部では、次の操作ができます。

- 表示倍率の確認と変更
- 地図の回転
- `前→現ルート` と `現在地` の中心合わせ切り替え

地図上のセルを押すと、そのセルに紐づくアイテム一覧を確認できます。追加が許可されている場合は、セルのポップアップから新規アイテムを追加できます。

## 新規アイテムを追加する

集中モード中でも、現在の訪問先にアイテムを追加できます。アイテム一覧の下部にある `+` ボタンを押すと、追加ダイアログが開きます。

追加時には、次の項目を入力できます。

- サークル名
- タイトル
- 参加日
- ブロック
- ナンバー
- 予定価格
- 数量
- 購入状態
- 備考
- URL

サークル名は必須です。参加日・ブロック・ナンバーは現在の訪問先をもとに初期入力されます。

## 編集・削除する

アイテムカードから、実行モードと同じように数量、価格、備考、購入状態を変更できます。サークル名、参加日、ブロック、ナンバー、タイトル、URLなどを編集したい場合は、カードのメニューから `編集` を選びます。

不要なアイテムはカードのメニューから `削除` できます。削除は実行対象から外す操作ではなく、リスト内のアイテム自体を削除する操作です。

## 中断後に再開する

集中モードを離れても、現在のフェーズや訪問先の位置は保存されます。再度集中モードを開くと、状況に応じて再開位置を選ぶダイアログが表示されます。

- 最後に購入状態を変更したスペース
- 離脱時のポインタ位置
- 現在のフェーズの最初から
- 通常フェーズの最初から

現地でいったん画面を閉じた場合でも、直前の作業位置から再開できます。

## 完了後にできること

すべての訪問先を確認すると、完了画面が表示されます。完了画面では、購入済み、売切、欠席、後回し、遅参、未処理の件数と、購入金額の集計を確認できます。

完了後は、`編集モードへ` または `実行モードへ` から別モードへ戻れます。PC表示では前へ戻るボタン、スマートフォン表示では右スワイプで最後の訪問先に戻ることもできます。
