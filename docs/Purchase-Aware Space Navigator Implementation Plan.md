# スペースナビ実装プラン

実行モードと集中モードに共通の「スペースナビ」を追加します。細い色帯と固定フッター内の一覧ボタンを入口とし、最大300訪問でも正確に選択できる構成です。

## 1. 確定した基本定義

### 訪問先の単位

- ブロック＋基準スペース番号＋優先度で1訪問を識別
- 同じA-01でも「最優先」と「通常」は別訪問
- 各訪問の色帯区画は同じ長さ
- 色帯内に文字は表示しない
- 集中モードではフェーズも識別子へ含める
  - `通常:A-01:highest`
  - `後回し:A-01:highest`

現在重複している実行・集中・マップのスペース番号判定を、共通処理へ統一します。

### 状態色

| 分類     | 対象                                       |
| -------- | ------------------------------------------ |
| グレー   | 未購入                                     |
| 紫       | 後回し                                     |
| 青       | 遅参                                       |
| オレンジ | 限数・実購入数未入力                       |
| 緑       | 購入済、売切、欠席、実購入数入力済みの限数 |
| 警告線   | 価格未定などの入力警告                     |

混在時は、存在する分類を同じ幅で分割します。順序は「未購入→後回し→遅参→限数→完了」で固定します。

警告線は価格・限数の遷移ブロック設定をOFFにしても表示を残します。

## 2. 共通状態モデル

正式な進行位置と、一時的に見ている位置を分離します。

- 正式位置
  - 集中モードの次／前、再開位置に使う
  - 恒久移動時だけ更新
- 表示位置
  - 一時移動や内容確認で使用
  - 正式位置には影響しない
- 戻り履歴
  - メモリ上の履歴として積み重ねる
  - ページ再読み込み時には保存しない

```text
通常表示
  ↓ ナビをドラッグ
候補選択
  ↓ 表示中の任意行をクリック／タップ
移動方法ダイアログ
  ├─ 現在地として移動 ─→ 正式位置更新・履歴消去
  ├─ 一時移動して操作 ─→ 履歴追加・編集可能
  └─ 内容だけ確認     ─→ 履歴追加・閲覧専用

一時移動先
  ├─ さらに一時移動 ─→ 履歴を追加
  ├─ 元へ戻る       ─→ 履歴を1件戻す
  └─ 現在地にする   ─→ 正式位置更新・履歴消去
```

## 3. 移動方法ごとの動作

| 操作                     | 入力チェック       | 正式位置       | 編集           | 戻り履歴 |
| ------------------------ | ------------------ | -------------- | -------------- | -------- |
| 現在地として移動         | 前方移動時に実施   | 更新           | 可             | 全消去   |
| 一時移動して操作         | 前方移動時に実施   | 変更しない     | 可             | 1件追加  |
| 内容だけ確認             | 実施しない         | 変更しない     | 不可           | 1件追加  |
| 元のスペースへ戻る       | 実施しない         | 変更しない     | 元の状態へ復帰 | 1件削除  |
| 一時移動先を現在地にする | 原則再チェック不要 | 表示位置で更新 | 可             | 全消去   |

入力チェックは移動元の現在スペースだけを対象とし、飛ばす途中のスペースはブロックしません。

- 価格未定：設定が有効なら移動停止
- 限数未入力：設定が有効なら移動停止
- 未購入：警告後に移動可能
- 後方移動／戻る：停止しない
- ブロック無効設定：既存設定をそのまま反映

### 色付きナビ

- 初期位置は左
- 見た目と操作範囲はともに16px
- 見た目より広い透明な操作範囲は設けない
- 本文幅を狭めず、画面上へ重ねる
- 現在地は状態色を残したまま枠または矢印で表示
- 通常／後回し／遅参の境界線を追加
- アプリ倍率の影響を受けないよう、画面直下へPortal表示

### ドラッグ操作

Pointer Eventsでスマートフォン、タブレット、マウスを共通処理します。

1. 色帯を押すと一覧エリアを展開
2. 5pxを超えてドラッグした時点でPointer Captureを開始し、通常のPCクリックを妨げずに操作を継続
3. 候補番号だけを変更し、メイン画面は動かさない
4. 指を離すと中央線へ吸着
5. 一覧エリア内から再度ドラッグ可能
6. PCではマウスホイール／トラックパッドでも候補を前後へ移動
7. スマートフォン／PCとも、表示中の任意行をタップ／クリックすると、その訪問の3択ダイアログを表示
8. ドラッグ終了だけでは移動しない
9. 一覧外タップは移動せず閉じる

ドラッグ中は購入状態の再集計を行わず、座標から候補番号だけを計算します。

### 拡大一覧

- スマートフォン：画面幅の約90％を覆うシート
- タブレット：設定した側から開く最大420px程度のパネル
- 一覧全体をドラッグ可能
- 一覧の実測高に合わせて表示行数を増減し、パネル内の未使用領域を実アイテムで埋める
- 先頭・末尾付近や表示件数が少ない場合も範囲外の空行を作らない
- 中央線と前・選択中・次を強調
- サークル名は2件＋「ほかN件」
- フェーズ、優先度、状態件数、警告を表示
- 300訪問対応として必要なら表示行を仮想化

## 7. 実行モードへの組み込み

主な変更先：

- [ShoppingList.tsx](D:/event-shopping-planner-routeplanning-1.9.6.6/src/components/ShoppingList.tsx)
- [ShoppingItemCard.tsx](D:/event-shopping-planner-routeplanning-1.9.6.6/src/components/ShoppingItemCard.tsx)
- [AppMainContent.tsx](D:/event-shopping-planner-routeplanning-1.9.6.6/src/features/app-shell/components/AppMainContent.tsx)
- [AppOverlayLayer.tsx](D:/event-shopping-planner-routeplanning-1.9.6.6/src/features/app-shell/components/AppOverlayLayer.tsx)

実装内容：

1. 現在の絞り込み後アイテムからナビ訪問先を生成
2. 各スペース見出しと先頭アイテムへ安定したアンカーを付与
3. 画面中央に最も近いスペースを現在地として追跡
4. スペース別表示ON
   - 対象を展開
   - 他のスペースは変更しない
   - 対象見出しを中央へスクロール
5. スペース別表示OFF
   - 表示方法を変更しない
   - 対象の先頭アイテムへスクロール
6. 一時移動前に以下を保存
   - 訪問先ID
   - スクロール位置
   - 画面中央からの相対位置
7. 戻る際はアンカー＋相対位置で復元し、見つからない場合のみ保存スクロール位置を使用
8. 内容確認中はカードの購入状態、価格、数量などの変更操作を無効化

絞り込みで対象が消えた場合は、絞り込みを勝手に変更せず、最も近い表示可能な訪問先へ補正して通知します。

## 8. 集中モードへの組み込み

主な変更先：

- [FocusMode.tsx](D:/event-shopping-planner-routeplanning-1.9.6.6/src/components/FocusMode.tsx)
- [FocusModeMapCanvas.tsx](D:/event-shopping-planner-routeplanning-1.9.6.6/src/components/FocusModeMapCanvas.tsx)
- [FocusModeContainer.tsx](D:/event-shopping-planner-routeplanning-1.9.6.6/src/features/map/components/FocusModeContainer.tsx)

実装内容：

1. 通常→後回し→遅参の全訪問を連続したナビ配列にする
2. 同じスペースをフェーズごとに別エントリーとして残す
3. 正式な`phase/index`と一時表示位置を分離
4. 一時移動中は既存セッションの再開位置を書き換えない
5. 恒久移動時のみ正式なフェーズと位置を更新
6. 一時移動中の購入状態変更は保存する
7. 一時移動中は自動進行タイマーを停止
8. 内容確認中は編集、前後移動、左右スワイプを停止
9. 手動の一時操作中に次／前へ進んでも、正式位置は変更しない
10. マップは表示位置へ再センタリング
11. 経路表示は確定どおり「予定上の直前訪問→対象」を維持
12. 戻ると元フェーズ、訪問位置、マップ位置へ復帰

後回し／遅参アイテムが状態変更で対象フェーズから消えた場合も、一時表示中は対象を保持します。そこで恒久移動した場合は、同じ訪問先の通常フェーズ位置へ安全に対応付けて通知します。

## 9. 競合対策

- ナビ操作開始時に自動進行タイマーを確実に破棄
- ナビ表示中は背景スクロールと集中モードの横スワイプを停止
- ダイアログ中は追加のドラッグや二重実行を無効化
- 閉じた後は以前のスクロール設定を正確に復元
- マップのパン・ピンチ・セルタップへイベントを伝播させない
- 既存の固定ボタンと重なる場合はナビ表示中だけ既存ボタンを退避
- 左端のOS「戻る」ジェスチャーを実機確認
- 左端操作が難しい端末でも、固定フッターの一覧ボタンを代替導線として維持
- ライト／ダークテーマで現在地枠と警告線のコントラストを確保

6. 実行モードのアンカー・スクロール・閲覧専用を接続

10. 実機・回帰・アクセシビリティ確認

各段階でテストを通してから次へ進み、実行モードと集中モードを同時に大きく変更しない進め方にします。
