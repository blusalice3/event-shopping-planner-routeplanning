# 1. 改修目的

集中モードのマップ上で、正式な巡回順を変えずに、通りがかったスペースの商品を一時的に表示・購入できるようにします。

同時に、集中モードのスペース情報ヘッダーを、表示中商品の購入状態に応じた色へ変更します。

# 2. 基本状態モデル

正式な巡回位置と、一時的な表示位置を明確に分離します。

| 状態 | 用途 |
|---|---|
| 正式位置 | 再開位置、予定ルート進捗、通常の前／次 |
| 一時表示位置 | マップから選んだスペースの商品表示・購入操作 |
| 移動基準フェーズ | 一時表示中の前／次の順序を決めるフェーズ |
| 一時移動履歴 | 多段一時移動から元の表示へ戻るための履歴 |

一時移動中に商品を更新しても、正式位置・再開位置・予定ルート進捗は変更しません。

# 3. マップセルのポップアップ

## 対象商品

ポップアップへ表示するのは次の条件を満たす商品のみです。

- 現在の開催日
- 今回の集中モードの巡回対象
- クリックしたマップセルと同じブロック・数値部分

別開催日や巡回対象外の商品は表示しません。

対象がない場合は「このセルには今回の巡回対象アイテムがありません」と表示し、一時移動ボタンを出しません。既存の商品追加機能は変更しません。

## ヘッダー

従来のタイトルは操作不可のまま維持します。

```text
Y-12（3件）
```

タイトルの右側へ、アルファベット付き番号ごとの青いボタンを配置します。

```text
Y-12（3件）
[Y-12aに一時移動] [Y-12bに一時移動] [×]
```

仕様は次のとおりです。

- ボタン文言全体が収まる幅
- ポップアップ全幅には広げない
- 狭い画面ではヘッダー内で折り返す
- アルファベットなし→a→b→cの自然順
- `12a1`、`12a2`は既存ルールどおり同じ`12a`へ集約
- 比較時は大文字・小文字を同一扱い
- 表示は登録データの表記を維持
- 現在表示中のスペースは無効化して二重移動を防止

# 4. マップからの一時移動

`Y-12aに一時移動`を押した場合、Y-12aにある巡回対象商品を次の区別なく重複排除してすべて表示します。

- 通常／後回し／遅参
- 最優先／優先／通常
- 同一商品のフェーズ重複

フェーズ・優先度の候補選択画面は、一時移動開始時には表示しません。

一時移動ボタンは即時実行とし、現在の正式スペースに以下が残っていても移動できます。

- 未購入
- 価格未定
- 限数の実購入数未入力

この確認省略はマップポップアップからの一時移動だけに限定します。既存の色付きナビや正式な前／次では、従来の入力確認を維持します。

# 5. 一時表示中のヘッダー

一時表示中はフェーズ選択欄を操作不可にし、次のように表示します。

```text
一時表示・全フェーズ
移動基準：未選択
```

フェーズ選択後は次の表示になります。

```text
一時表示・全フェーズ
移動基準：通常
```

スペース名、金額、件数、一括購入状態ボタンは、まとめて表示している全商品から計算します。

サークル名が複数ある場合は、先頭2件と「ほかN件」で表示します。

# 6. 一括購入状態変更

「全購入」「全売切」「全欠席」などの一括ボタンは、一時表示中も利用可能にします。

操作対象は、その画面にまとめて表示している全フェーズ・全優先度の商品です。

限数の一括変更は、既存の実購入数入力フローを商品ごとに継続します。

一時移動中は、購入状態変更による自動進行を発生させません。全商品が完了しても、利用者が明示的に戻るまでその画面に留まります。

# 7. 最初の前／次操作

マップから一時移動した直後は、移動基準フェーズを未選択にします。

最初に前または次を押したとき、通常・後回し・遅参ごとの実際の移動先を表示します。

```text
通常：Z-20 サークル名（2件）
後回し：P-03 サークル名（1件）
遅参：L-08 サークル名（3件）
```

各フェーズの基準位置は、そのフェーズ内で現在のスペースに一致する最も早い訪問候補とします。

同じスペースに優先度違いがあっても、同じ場所をもう一度表示しません。

```text
A-01
→ Y-12a（最優先）
→ Y-12a（通常）
→ Z-20
```

Y-12aから通常フェーズの「次」を選んだ場合は、Z-20へ移動します。

# 8. フェーズ選択後の前／次

一度フェーズを選択した後は、そのフェーズを移動基準として保持します。

- 以後の前／次ではフェーズ選択を再表示しない
- 移動先でも全フェーズ・全優先度の商品をまとめて表示
- 前／次による移動では戻り履歴を増やさない
- 新たにマップから別セルへ一時移動したときだけフェーズ選択をリセット
- 多段履歴から戻った場合は、以前の移動基準フェーズを復元

前方向の移動では、既存の価格・限数チェックを維持します。後方向の移動は入力状態で停止させません。

# 9. 「前」のフェーズ境界

| 現在位置 | 「前」の動作 |
|---|---|
| 通常フェーズの先頭 | その場に留まり「前のスペースはありません」 |
| 後回しフェーズの先頭 | 通常フェーズの最後の異なるスペースへ移動 |
| 遅参フェーズの先頭 | 後回しフェーズの最後の異なるスペースへ移動 |
| 遅参先頭で後回しが0件 | 通常フェーズの最後の異なるスペースへ移動 |
| 通常にも移動先がない | その場に留まって通知 |

フェーズ境界で選択ポップアップは表示しません。

移動後は移動基準フェーズも自動的に切り替えます。

# 10. 「次」のフェーズ終端

選択中フェーズの最後で「次」を押すと、終端選択画面を表示します。

画面には常に次を用意します。

- `ここで一時巡回を終了`
- 通常の未購入スペース一覧
- 後回しスペース一覧
- 遅参スペース一覧

例：

```text
通常の未購入
  B-02 サークル名（2件）

後回し
  P-03 サークル名（1件）
  P-05 サークル名（3件）

遅参
  L-08 サークル名（1件）
```

残り一覧の定義は次のとおりです。

- 通常：購入状態が未購入
- 後回し：購入状態が後回し
- 遅参：購入状態が遅参
- 現在の開催日・巡回対象のみ
- スペース単位で集約
- 各フェーズのルート順
- 現在表示中のスペースは「表示中」として無効化

同じスペースが複数区分に該当する場合は、それぞれの区分へ表示します。選択した区分が新しい移動基準フェーズになります。

一覧は画面表示時と選択時に再集計し、購入状態変更で消えた候補へ誤移動しないようにします。

# 11. 一時巡回の終了画面

`ここで一時巡回を終了`を押しても、集中モード全体は正式完了にしません。

専用の「一時巡回の終端」画面を表示します。

変更しない状態：

- 正式現在地
- 正式フェーズ
- 再開位置
- 集中モードの完了状態
- 予定ルート進捗
- 一時移動履歴

画面には次を表示します。

- 購入済み件数
- 未購入件数
- 後回し件数
- 遅参件数
- 売切・欠席件数
- 限数未入力件数
- 価格未定件数
- 購入合計・予定合計

操作：

- 元のスペースへ戻る
- 現在地にする
- 残りスペース一覧へ戻る

残件があっても「すべて完了」とは表示せず、「一時巡回を終了しました」と表示します。

# 12. 「現在地にする」

全フェーズまとめ表示には単独のフェーズがないため、「現在地にする」を押した場合もフェーズ選択を表示します。

```text
通常：Y-12aを現在地にする
後回し：Y-12aを現在地にする
遅参：Y-12aを現在地にする
```

選択したフェーズ内に優先度違いがある場合は、ルート上で最も早い候補を正式位置にします。

確定後は以下を行います。

- 正式フェーズ・正式位置を更新
- 再開位置を更新
- 一時移動履歴を全消去
- 一時表示を終了
- 予定ルート進捗を新しい正式位置へ更新

# 13. 多段一時移動

マップから別のセルへさらに一時移動した場合は、履歴を積み重ねます。

```text
正式 A-01
→ 一時Y-12a
→ 通常を選択してZ-20
→ マップから一時W-05
```

戻る順序：

```text
W-05 → Z-20 → A-01
```

履歴には次を保存します。

- 表示スペース
- 表示商品ID
- 移動基準フェーズ
- フェーズ選択済みか
- 終端画面／残り一覧の表示状態
- マップ中心位置
- 直前の一時移動モード

Z-20へ戻った場合は「移動基準：通常」も復元し、前／次で再確認しません。

# 14. マップ表示

正式現在地と一時移動先を別の見た目にします。

| 対象 | 表示 |
|---|---|
| 正式現在地 | 既存のオレンジ実線枠・ピン |
| 一時移動先 | 青系の太い破線二重枠・「一時」表示 |
| 同じセル内の別番号 | オレンジ実線と青破線を重ねる |

一時移動中も予定ルートの進捗色は正式位置だけを参照します。

例として、正式ルートが`A-01 → B-02 → Y-12a`の場合：

- A-01は正式現在地のまま
- Y-12aを一時移動先として強調
- B-02以降を訪問済み表示にしない
- A-01からY-12aへの臨時ルート線は追加しない
- マップの表示中心だけY-12aへ移す
- 戻るとA-01へ再センタリング

# 15. ヘッダーの購入状態色

判定対象は、現在ヘッダーと商品一覧に表示している全商品です。

| 色 | 状態 |
|---|---|
| グレー | 未購入 |
| 紫 | 後回し |
| 青 | 遅参 |
| オレンジ | 限数の実購入数未入力 |
| 緑 | 購入済・売切・欠席・入力済み限数 |

混在時は、存在する分類を件数比ではなく均等幅で左から並べます。

固定順：

```text
未購入 → 後回し → 遅参 → 限数未入力 → 完了
```

例：

- 未購入9件＋完了1件：グレー50%・緑50%
- 後回し＋遅参＋完了：紫・青・緑を各3分の1
- 全完了：全面緑

白文字の可読性を確保するため、状態色の上へ一様な半透明の暗幕を重ねます。

価格未定は購入状態色へ含めず、既存の赤い警告文を維持します。

スマートフォン、PC、マップ表示・非表示、上下分割・左右分割の全ヘッダーへ適用します。

# 16. ナビ表示設定

「細い色付きナビ」と「フッターのスペース一覧」が両方OFFでも、マップセルからの一時移動は利用可能にします。

一時移動中だけ、画面上部へ次を表示します。

- 一時移動中のスペース
- 元へ戻る
- 現在地にする

一時移動中にナビ設定をOFFへ変更しても履歴を破棄しません。

集中モード終了、開催日変更、対象イベント変更時には安全に履歴を破棄します。

# 17. 内部実装方針

既存の「単一訪問先を表示する一時移動」に加え、「スペース単位で商品を集約する一時移動」を追加します。

一時表示スナップショットには次を保持します。

```text
表示種別：単一訪問／スペース集約
スペースID
表示商品ID一覧
代表訪問先ID
移動基準フェーズ
フェーズ選択済み状態
一時終端サブ画面
```

代表訪問先IDはナビ・ルートとの接続に使用しますが、商品表示には集約済み商品IDを使用します。

候補は配列番号ではなく安定した訪問先IDで保存し、実行直前に最新の一覧から再解決します。

# 19. 競合・誤操作対策

- タップ直後に同期的な処理中ロックを設定
- 二重タップで履歴を重複追加しない
- モーダル表示中は背景スクロール、スワイプ、マップ操作を停止
- マップのパン・ピンチへボタン操作を伝播させない
- 自動進行タイマーを一時移動開始時に停止
- 一時移動中は正式なセッション状態を書き換えない
- 候補選択時に開催日・登録ID・訪問先IDを再確認
- 購入状態変更で消えた候補は選択せず通知
- 残り一覧を選択時に再集計
- 一時終端画面で正式な`isCompleted`を変更しない
- 同一商品を集約表示で重複更新しない
- 内容確認モードでは一時移動・編集を許可しない
- ライト／ダークテーマで文字コントラストを確保

データ形式、インポート／エクスポート形式、保存済み集中モードセッションの形式は変更しません。一時移動状態はメモリ上だけに保持します。
