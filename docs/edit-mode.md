# 編集モードの操作方法

編集モードは、参加日ごとに「当日まわるアイテム」を整理するための画面です。候補アイテムから実行リストへアイテムを移動し、巡回順やスペース単位のまとまりを調整します。

## 編集モードを開く

1. `イベント一覧` から対象の即売会リストを選択します。
2. 操作したい参加日タブを開きます。
3. ヘッダー右側の `編集モード` ボタンを押します。

新規リスト作成直後は、各参加日が編集モードで初期化されます。

## 画面構成

編集モードでは、画面が2列に分かれます。

- `実行リストアイテム`: 当日まわる対象として選択済みのアイテムです。実行モードや集中モードでは、このリストをもとに巡回します。
- `候補アイテム`: まだ実行リストに入っていないアイテムです。ここから必要なアイテムを実行リストへ移動します。

各参加日タブには、その参加日に属するアイテムだけが表示されます。

## 候補アイテムを実行リストへ移動する

候補アイテムを実行リストに入れる方法は以下の通りです。

### チェックして単一・まとめて移動する

候補アイテムのチェックボックスをオンにすると、1つまたは複数アイテムを選択できます。選択後、ヘッダーに表示される `選択したアイテムを実行列に移動` を押すと、選択中の候補アイテムが実行リストへ移動します。

同じスペースかつ同じ優先度のアイテムがある場合は、選択したアイテムだけでなく、そのスペース内の同条件アイテムもまとめて移動対象になります。

## 実行リストから候補へ戻す

実行リスト側のアイテムを候補へ戻す場合も、候補アイテムを実行リストに移動する方法と同様に以下の様にします。

- 実行リストのアイテムにチェックを入れ、`選択したアイテムを実行列から戻す` を押す

候補へ戻すと、その参加日の実行リストからは外れますが、アイテム自体は削除されません。

## 並べ替え

### ドラッグで順番を変える

実行リスト内、候補アイテム内のどちらでも、ドラッグ＆ドロップで順番を変更できます。複数選択中のアイテムをドラッグした場合は、選択中のアイテムがまとまって移動します。

実行リスト側では、ホールや優先度のまとまりを壊さないように移動できる範囲が制限される場合があります。

### 上下ボタンで移動する

各カードの上部にある上下ボタンで、アイテムを1つ上または下へ移動できます。移動できない位置ではボタンが無効になります。

### 選択中アイテムを番号順に並べ替える

アイテムを複数選択すると、ヘッダーに一括操作が表示されます。昇順または降順の並べ替えを選ぶと、選択中のアイテムだけをナンバー順に並べ替え、元の選択範囲の先頭位置へ戻します。

候補アイテム側では、ブロックで絞り込んだ状態の候補だけを番号順に並べ替えることもできます。

## 候補アイテムの絞り込み

候補アイテム欄には `ブロックでフィルタ` が表示されます。ブロック名のボタンを押すと、そのブロックの候補だけに絞り込めます。

- 複数のブロックを同時に選択できます。
- `すべて解除` でフィルタを解除します。
- フィルタ中に番号順ボタンを押すと、表示中の候補だけを昇順または降順で並べ替えます。
- 優先や委託なしなどの備考を含む候補があるブロックは、黄色で表示されます。

## スペース別表示

`スペース別` をオンにすると、同じ `ブロック` と `ナンバー` のアイテムがスペース単位でまとまって表示されます。

スペース別表示では、次の操作ができます。

- スペース見出しをクリックして展開・折りたたみする
- `全て折りたたむ` / `全て展開` で一括切り替えする
- 折りたたんだスペース見出しをドラッグして、スペース単位で並べ替える
- 折りたたんだスペース見出しのチェックボックスで、スペース内のアイテムをまとめて選択する
- スペース見出しの上下ボタンで、スペース単位で前後へ移動する

スペース別表示中に `+` ボタンを押すと、そのスペースへ新規アイテムを追加できます。参加日は現在のタブ、ブロックとナンバーは対象スペースの値が初期入力されます。

## アイテム情報の編集

カード上では、次の項目を直接変更できます。

- `備考`
- `数量`
- `頒布価格`
- `購入状態`

購入状態は、設定によって操作方法が変わります。

- `循環クリック`: 状態ボタンを押すたびに次の状態へ切り替わります。
- `放射状メニュー`: 状態ボタンを押すと状態選択メニューが開き、任意の状態を直接選べます。

購入状態には、`未購入`、`購入済`、`売切`、`欠席`、`後回し`、`遅参`、`限数` があります。

サークル名、参加日、ブロック、ナンバー、タイトル、URLなどを含めて編集したい場合は、カードを長押しして表示されるメニューから `編集` を選びます。長押しメニューからは `削除` も選べます。

## 新規アイテムの追加

スペース別表示中は、スペース見出し付近の `+` ボタンから新規アイテムを追加できます。

追加ダイアログでは、次の項目を入力できます。

- サークル名
- タイトル
- 参加日
- ブロック
- ナンバー
- 頒布価格
- 数量
- 購入状態
- 備考
- URL

`サークル名` は必須です。追加されたアイテムはアプリ内で作成されたアイテムとして扱われ、既定では更新・削除から保護されます。

## 削除

カードを長押ししてメニューを開き、`削除` を選ぶと削除確認が表示されます。確認すると、そのアイテムはリストから削除されます。

候補へ戻す操作とは異なり、削除はアイテム自体を消す操作です。

## 保護レベル

アプリ内で追加したアイテムやスプレッドシート由来のアイテムには、保護レベルがあります。カード上の保護アイコンを押すと、次の順で切り替わります。

- `完全保護`: 更新も削除もされません。
- `削除のみ許可`: 更新はされず、削除は許可されます。
- `保護なし`: 更新も削除も許可されます。

スプレッドシート更新や差分反映を使う場合、手動で追加・修正したアイテムを誤って上書きしたくないときに利用します。

## 検索

参加日タブ内では検索欄を使えます。検索に一致したアイテムは、実行リストと候補アイテムの両方を対象に探されます。次へ進む操作を行うと、一致したカードへスクロールし、対象カードが強調表示されます。

## 実行モードへ進む

実行リストの整理が終わったら、ヘッダーの `実行モード` を押します。実行モードでは、編集モードで組んだ実行リストをもとに購入チェックや巡回作業を進めます。
