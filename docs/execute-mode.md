# 実行モードの操作方法

実行モードは、編集モードで作成した実行リストをもとに、当日の購入状況を記録しながら巡回するための画面です。候補アイテムは表示対象ではなく、実行リストに入っているアイテムだけを扱います。

## 実行モードを開く

1. `イベント一覧` から対象の即売会リストを選択します。
2. 操作したい参加日タブを開きます。
3. ヘッダー右側の `実行モード` ボタンを押します。

実行モードへ入る前に、編集モードで候補アイテムを実行リストへ移動しておきます。

## 基本の流れ

1. 実行リストの上から順にアイテムを確認します。
2. 購入結果に合わせて、各アイテムの購入状態を変更します。
3. スペース別表示を使っている場合は、スペース内の全アイテムを処理します。
4. `スペースを閉じて次のスペースを展開` を押して次のスペースへ進みます。
5. 未購入のアイテムがなくなったら、必要に応じて `後回しでフィルタ` や `遅参でフィルタ` に切り替えます。

## 購入状態を変更する

各カードの購入状態ボタンで、購入結果を記録します。状態は次の種類があります。

- `未購入`
- `購入済`
- `売切`
- `欠席`
- `後回し`
- `遅参`
- `限数`

購入状態ボタンの操作方式は、表示設定の `購入状態ボタン` で変更できます。

- `循環クリック`: クリックするたびに次の状態へ切り替わります。
- `放射状メニュー`: クリックすると状態選択メニューが開き、目的の状態を直接選べます。

購入済、売切、欠席、限数などの完了扱いの状態になると、カードの表示が薄くなり、タイトルに取り消し線が入ります。後回しや遅参は後で再確認するため、完了扱いの薄い表示にはなりません。

## 数量・価格・備考を変更する

実行モード中でも、カード上で次の項目を変更できます。

- `数量`
- `頒布価格`
- `備考`

価格欄では `価格未定` も選べます。購入済にしたアイテムの価格が未定のまま次へ進もうとすると、価格欄が強調表示されます。

## スペース別表示

実行モードでは、ヘッダーまたはタブバー付近の `スペース別` をオンにすると、同じ `ブロック` と `ナンバー` のアイテムがスペース単位でまとまります。

スペース別表示では、次の操作ができます。

- スペース見出しをクリックして展開・折りたたみする
- `全て折りたたむ` / `全て展開` で一括切り替えする
- 折りたたみ中のスペース見出しで、購入状態の件数サマリーを確認する
- 展開中のスペース内で、一括ステータス変更を行う
- スペース内の処理完了後、次のスペースへ進む

折りたたみ中のスペースには、購入状態の略称と件数が表示されます。

```text
未2 購1 後1
```

これは、未購入が2件、購入済が1件、後回しが1件あることを表します。

## スペース内を一括で処理する

スペースを展開すると、スペース見出し付近に一括変更ボタンが表示されます。

- `全購入`
- `全売切`
- `全欠席`
- `全後回`
- `全遅参`
- `全限数`

ボタンを押すと、スペース内の全アイテムが指定した購入状態になります。すでにスペース内の全アイテムが同じ状態になっている場合、同じボタンをもう一度押すと `未購入` に戻ります。

## 次のスペースへ進む

スペース内の全アイテムが `未購入` 以外の状態になると、最下段以外のスペースでは `スペースを閉じて次のスペースを展開` が表示されます。

このボタンを押すと、現在のスペースを折りたたみ、次のスペースを展開します。会場で順番に処理していくときの主な進行操作です。

購入済のアイテムに価格未定が残っている場合は、価格欄が強調され、通常は次のスペースへ進めません。表示設定で `価格未定チェックを無効化` をオンにすると、警告表示は残したまま次へ進めます。

## 後回し・遅参フィルタ

実行リスト全体の未購入アイテムがなくなると、最後のスペースに `後回しでフィルタ` が表示されます。押すと、購入状態が `後回し` のアイテムだけを中心に再表示します。

後回しフィルタ中に表示されているアイテムを処理し終えると、最後のスペースに `遅参でフィルタ` が表示されます。押すと、購入状態が `遅参` のアイテムだけを中心に再表示します。

フィルタ中に購入状態を変更した直後のアイテムは、状態確認のため一時的に表示に残ります。ヘッダーの状態フィルタを切り替えると、この一時表示はリセットされます。

## 状態フィルタを手動で切り替える

ヘッダーには現在の表示状態を表すボタンがあります。初期状態は `巡回順` です。押すたびに、次の順で表示対象が切り替わります。

```text
巡回順 → 後回し → 遅参 → 欠席 → 売切 → 未購入 → 購入済 → 巡回順
```

`巡回順` では実行リスト全体を表示します。それ以外の状態では、選んだ購入状態のアイテムを表示します。

## 検索

検索欄にキーワードを入力すると、現在表示対象になっている実行リスト内から一致するアイテムを探します。次へ進む操作を行うと、一致したカードへスクロールし、対象カードが強調表示されます。

状態フィルタ中は、現在の絞り込み条件で表示されているアイテムが検索対象になります。一致する項目があっても現在の絞り込みでは表示されない場合は、通知が表示されます。

## アイテムの編集・削除

実行モード中も、カードを長押しすると操作メニューを開けます。

- `編集`: アイテム情報を編集します。
- `削除`: アイテムをリストから削除します。

削除は候補へ戻す操作ではなく、アイテム自体を消す操作です。実行対象から外すだけの場合は、編集モードへ戻して実行リストから候補へ戻してください。

## 新規アイテムの追加

スペース別表示中は、スペース見出し付近の `+` ボタンから、そのスペースに新規アイテムを追加できます。参加日、ブロック、ナンバーは現在のスペースをもとに初期入力されます。

追加時は、サークル名、タイトル、価格、数量、購入状態、備考、URLを入力できます。`サークル名` は必須です。

## 編集モード・集中モードへ切り替える

実行リストの組み直しが必要になった場合は、ヘッダーの `編集モード` を押します。より1件ずつ集中して処理したい場合は、`集中モード` を押します。

実行モードから別モードへ切り替えると、選択状態や一時的なフィルタ表示はリセットされます。
